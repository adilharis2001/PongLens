# Lesson video pilot

Approved by Adil on 2026-09-05, including implementation and TestFlight deployment before his 90-minute lesson. Import-first: film with Camera, landscape 1080p/30, coach-side diagonal, then import. Broad existing iOS 26 device support. Preserve original and recap indefinitely unless owner deletes; no age-based sweep. Coach reviews before sharing.

Create a distinct lesson video record and queue, independent of matches and their 45-minute cap. Maximum import 3 hours and 20 GiB, supporting a 90-minute HEVC recording with headroom. Private media prefix `lesson-video/<owner>/<id>/` in ponglens-media. Multipart 64 MiB uploads verified against object size; retry after completion is idempotent. Store a durable local import file on iOS and persist upload state; no whole-video Data allocation.

API `/api/lesson-video`: authenticated GET list/detail, POST create/sign-part/list-parts/complete/retry/edit/share. Ownership is checked server-side, students read only explicitly shared ready results; source always owner-only. Detail response has video record plus signed media URLs. Optional student_id supports the author's own lesson; coach entries connect to existing lesson/coach_entries on approval. Raw transcription and generated edit are private until approval. Summary viewing on iOS and web, original download for owner. Only approved versions are shared. Editing revokes readiness until new render is reviewed.

Independent portable worker polls an atomic leased claim RPC. Pinned identical release on Mac and Modal, cloud claiming disabled until parity verified. Extract timestamped audio chunks, transcribe with existing Deepgram vocabulary, distill overlapping teaching windows then merge with source timestamps, choose contextual explanation/practice clips. Verify candidate frames with vision; do not invent technique conclusions. No dependence on BlurBall or match gates. Checkpoint transcript and edit; retry render independently. Render 3–7 minute chaptered MP4, coach voice, short side-by-side cues; adapt portrait in-app text below video. Fuller notes retained. Partial or unintelligible transcription is explicitly surfaced for review.

Pilot excludes native camera capture and Apple-only spatial cleanup, detailed timeline editing, synthetic narration, precise ball/pose analysis. Rendering and inference are asynchronous. No automatic student sharing.

Verification: independent access tests, 90-minute duration/20 GiB boundary, multipart completion recovery, source timestamp and edit validation, renderer with real ffmpeg, full npm build in isolated worktree, native simulator/device archive, production API smoke, TestFlight processing status. Never claim real-world 90-minute recording quality tested without such a recording.
